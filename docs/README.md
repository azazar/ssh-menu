# Shui documentation

Press **F1** in Shui to open help for the current screen: Guide, Profiles and Bindings from the host list, Setup from the remote setup dialog, Connection from one-off settings, or Profiles, Bindings and Setup from the configuration editor. Every context includes a live Keys topic. No network connection or separate documentation install is needed.

- [Using Shui](usage.md): navigation, shortcuts, host discovery, history, and Zellij.
- [Keybindings](keybindings.md): binding rules, modifier hints and connect-and-return behavior.
- [Launch profiles](configuration.md): profile behavior, placeholders, ports, and remote scripts.
- [One-off connection settings](connection.md): remote overrides and profile inputs.
- [Setting up a remote](setup.md): setup recipes, custom inputs, generated choices, and availability checks.
- [Installation](installation.md): release downloads, supported platforms, and source builds.
- [Development](development.md): testing, screenshots, and release workflows.

In help, use **Left/Right** or **Tab** to switch topics, **Up/Down** or **PgUp/PgDn** to scroll, and **Esc** or **F1** to return. **Home/End** jumps to the start or end of a topic.

Configuration examples and the default action map are maintained in [config comments](../shui-config.example.yml), also installed in new configurations and available through F9.
